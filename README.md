# itsjute.github.io

Plain static site – no Jekyll, no build step on GitHub (`.nojekyll`).

Everything except these files is **generated by `lab sync`** from the itsjute-lab
(projects with `webseite: öffentlich`, journal entries without `#privat`):

| File | Edit by hand |
|---|---|
| `site.json` | texts about you (name, tagline, intro, bio, tools) and your photos: `heroImage` (wide workshop photo), `heroCaption`, `portrait` – a path inside this folder or e.g. `P:/Automatic Upload/…jpg` |
| `assets/site.css` | the whole look |

Generated (do not edit, will be overwritten): `index.html`, `404.html`, `projects/`, `journal/`, `feed.xml`, `sitemap.xml`.

All photos – including hero and portrait – are converted by `lab sync` into web versions without GPS data and linked from the pCloud Public Folder, so they are never stored twice and never committed here.

Preview: open `index.html` in a browser. Publish: commit and push.
